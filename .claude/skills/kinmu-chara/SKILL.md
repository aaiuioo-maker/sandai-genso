# 勤務指定表のオレンジのキャラクターにする

オレンジのキャラクターの「ほんもの」は、勤務指定表のリポジトリ（aaiuioo-maker/kinmu-shitei）の `cc-chara.js` 1つにまとまっている。
絵・パソコンを打つ動き・夜にねる動き・250 とおりの動きが ぜんぶ入っていて、公開先はここ：

    https://aaiuioo-maker.github.io/kinmu-shitei/cc-chara.js

ほかのアプリは このファイルを**コピーせず、このURLを読みこむ**。そうすると、勤務指定表のキャラクターを直したとき、ほかのアプリも 何もしなくても 同じになる。

## 手順

1. いまのアプリで、オレンジのキャラクター（色 `#d97757` のドット絵）を描いているところを探す。
   どのキャラクターを入れかえるか はっきりしないとき（タイトルの横・字幕の横など いくつもあるとき）は、ユーザーに聞く。言われていなければ、タイトルの横の キャラクターだけにする。
2. そこに 次の絵の入れ物を置く（大きさは そのアプリに合わせて変えてよい。横:縦 = 34:23 のまま）：

   ```html
   <svg class="cc-anim" viewBox="0 -7 34 23" style="width:51px;height:34.5px;shape-rendering:crispEdges;overflow:visible" aria-hidden="true"></svg>
   ```

   - 絵の幅 34 マスのうち、キャラクターの体は左の 24 マス。右の約 10 マスは ノートパソコンが出る場所。
   - 上の 7 マスは 動きで 上にはみ出す分。
3. ページの中に 1回だけ、これを足す（`</body>` の前がよい。何度も足さない）：

   ```html
   <script src="https://aaiuioo-maker.github.io/kinmu-shitei/cc-chara.js"></script>
   ```

4. 前のキャラクターを描いていたプログラム（canvas に描く関数・その canvas・動かすループ）のうち、入れかえた所のものを消す。ほかの場所でまだ使っているものは消さない。
5. 背景が暗いときは、まわりの見え方（キャラクターが沈まないか）を確認する。
6. ブラウザで開いて、キャラクターが出て 動くことを確かめる（ローカルで確かめるときは、URL の代わりに 勤務指定表の `cc-chara.js` を読んでもよい。コミットする前に URL にもどす）。

## 知っておくこと

- 動きは `cc-chara.js` の中の時計で決まる。朝7時〜夜0時は動き、夜0時〜朝7時は ねている。
- 左上に いま出ている動きの番号が出るのは、勤務指定表の `cc-chara.js` の `SHOW_NO` が true だから。消したいときは 勤務指定表の方で直す（ほかのアプリも まとめて消える）。
- タップしたときの自己紹介の画面や GitHub のマークは 入っていない（勤務指定表だけのもの）。
- キャラクターの絵や動きを直したいと言われたら、そのアプリではなく 勤務指定表の `cc-chara.js` を直す。
