# COEIROINK の台詞「春の朝、動画棚の前で」

声：COEIROINK:つくよみちゃん・COEIROINK:MANA

- `serifu.txt` … 台詞（1行 =「話す人|台詞」）
- `tsukuru.py` … COEIROINK（v2）を起動しておいて `python tsukuru.py` で声を作る
- `out/00.wav`〜`09.wav` … 1行ずつの声、`out/zenbu.wav` … 全部つなげたもの（約42秒）

COEIROINK v.2.13.0（Linux CPU 版）で作成。
つくよみちゃん（れいせい）・MANA（のーまる）の声を使っています。
